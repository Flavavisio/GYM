# GYM Control v0.11

Projeto frontend em HTML, CSS e JavaScript, preparado para GitHub Pages.

## Entrada
O ficheiro principal é `index.html`.

## Login demo
- Admin: admin@gymcontrol.local / demo
- Receção: rececao@gymcontrol.local / demo
- Cliente: cliente@gymcontrol.local / demo
- Super Admin: superadmin@gymcontrol.local / demo

Também existem botões de entrada rápida no próprio login.

## GitHub Pages
Colocar todo o conteúdo do projeto na raiz do repositório.
Depois ativar GitHub Pages apontando para a branch principal e pasta `/ (root)`.

O site abrirá automaticamente no `index.html`.

## Nota
O login atual é apenas demonstração em localStorage.
Na fase Supabase será substituído por Supabase Auth com perfis/roles reais.
